# Цель и задачи лабораторной работы
Целью данной лабораторной работы является изучение рекуррентных последовательностей и применение методов динамического программирования для решения задач, связанных с вычислением членов последовательностей. Задачей было написать код, с помощью которого на выходе мы получим общее число кроличьих пар на n-ый месяц, если в
1-ый месяц есть всего одна пара, а у каждой пары половозрелых кроликов рождается помёт из k пар кроликов (вместо одной). 

# Инструменты и алгоритмы, использованные в этой работе
Для реализации данной задачи был использован язык программирования Python, код написан и реализован в программе PyCharm CE. Основным алгоритмическим подходом, применённым в данной работе, является метод динамического программирования. Он позволяет эффективно вычислять значения рекуррентных последовательностей, избегая повторных вычислений для уже известных значений.

Алгоритм:
1. Инициализация:
Создаётся список F длиной n + 1, заполненный нулями, и задаются начальные условия:  
   - F[1] = 1
   - F[2] = 1

2. Вычисление последовательности:
 Для каждого индекса от 3 до n по формуле вычисляется текущее значение популяции.

3. Возврат результата:
Функция возвращает значение F[n].

# Выводы
В результате выполнения лабораторной работы была успешно реализована программа, которая позволяет вычислить количество пар кроликов на заданный месяц с учётом заданного числа новорождённых пар. Программа продемонстрировала эффективность использования динамического программирования для решения задачи, обеспечивая быстрое вычисление значений даже для больших n (до 40).
На примере, при (n = 9) и (k = 3), программа вывела общее количество кроличьих пар, что подтверждает правильность алгоритма и его соответствие заданным условиям.
