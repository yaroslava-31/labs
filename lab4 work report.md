# Цель и задачи лабораторной работы
Цель данной лабораторной работы заключается в изучении работы с биологическими данными в формате GenBank, а также в применении библиотеки Biopython для обработки и анализа последовательностей ДНК. В рамках работы были поставлены следующие задачи:
1. Формирование исходного файла в формате GenBank, содержащего кодирующие области (CDS) двух биологических видов.
2. Вычисление и сортировка последовательностей по их GC-составам.
3. Вывод белковых последовательностей, полученных в результате трансляции кодирующих областей.
# Инструменты и алгоритмы, использованные в этой работе
Код был написан на языке программирования Python в программе PyCharm CE

Библиотека: Biopython, которая предоставляет инструменты для работы с биологическими данными, включая чтение и запись файлов в формате GenBank.

Алгоритм для 1 задания: 
Объединение файлов GenBank в один
1. Импортировать модуль SeqIO из библиотеки Bio.
2. Задать имена входных файлов (file1, file2) и имя выходного файла (output_file).
3. Открыть output_file на запись.
4. Для каждого файла:
    * Проанализировать входной файл с помощью SeqIO.parse, указав формат "genbank".
    * Для каждого записи в файле записать её в выходной файл с помощью SeqIO.write.
5. Вывести сообщение об успешном объединении файлов.

Алгоритм для 2 задания:
Вычисление и сортировка GC-состава
1. Импортировать модуль SeqIO из Bio.
2. Определить функцию gc_content(sequence), которая:
    * Считает число символов 'G' и 'C' в последовательности.
    * Делит сумму этих значений на длину последовательности (если длина не нулевая).
3. Создать пустой список records_gc для накопления данные о каждом записи.
4. Открыть файл combined_species.gb на чтение.
5. Для каждого записи, полученной через SeqIO.parse:
    * Вычислить GC-содержание с использованием функции gc_content.
    * Сохранить кортеж (id, описание, GC-содержание) в список records_gc.
6. Отсортировать список records_gc по возрастанию GC-содержания.
7. Вывести информацию (id, описание, GC) для каждой записи.

Алгоритм для 3 задания:
Извлечение CDS и их перевода
1. Импортировать модуль SeqIO из Bio.
2. Открыть файл combined_species.gb для чтения.
3. Для каждого записи, полученной через SeqIO.parse в формате "genbank":
    * Перебрать все элементы features записи.
    * Если тип элемента равен "CDS":
        * Извлечь переведённую последовательность белка из квалификаторов (ключ 'translation').
        * Получить информацию о расположении CDS (начало, конец и направление) из атрибута location.
        * Вывести идентификатор записи, описание, координаты CDS и переведённую последовательность.
