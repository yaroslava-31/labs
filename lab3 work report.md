# Цель и задачи лабораторной работы
Цель данной лабораторной работы заключалась в изучении методов визуализации данных с использованием Python. Задачи, поставленные в рамках работы, включали:
1. Построение диаграммы рассеяния на основе данных о цветах ириса, с использованием различных цветов для обозначения классов.
2. Построение графика динамики временных рядов для анализа изменений уровней CO2 за определенный временной промежуток.
# Инструменты и алгоритмы, использованные в этой работе
Код написан на языке программирования Python в программе PyCharm CE.
Были использованы следующие инструменты и библиотеки:
* Pandas: для работы с табличными данными и их предобработки.
* Seaborn: для построения диаграммы рассеяния с улучшенной эстетикой.
* Matplotlib: для создания графиков и визуализации данных.
* Scikit-learn: для загрузки набора данных о цветах ириса.
* Statsmodels: для работы с временными рядами, в частности для загрузки данных о уровнях CO2.
Для первого задания была использована диаграмма рассеяния, которая позволяет визуально оценить связь между двумя переменными, а также различия между классами. Во втором задании был построен линейный график, который наглядно демонстрирует динамику изменения уровней CO2 во времени.

Алгоритм для задания 1:
1. Импортировать библиотеки.
2. Загрузить данные Iris и создать DataFrame.
3. Добавить столбцы с метками классов и их строковыми значениями.
4. Построить и оформить scatterplot по длине и ширине чашелистика с цветовой дифференциацией по видам.
5. Отобразить график.

Алгоритм для задания 2:
1. Импортировать необходимые библиотеки и загрузить набор данных CO₂.
2. Вывести первые строки данных для проверки структуры.
3. Очистить данные от пропущенных значений.
4. Отфильтровать данные, оставив записи с 1958 по 1980 год.
5. Построить линейный график, где по оси X – временной индекс, по оси Y – уровни CO₂.
6. Оформить график (заголовок, подписи, легенда, сетка) и отобразить его.

# Выводы
В результате выполнения лабораторной работы были достигнуты следующие результаты:
1. Построенная диаграмма рассеяния для набора данных о цветах ириса продемонстрировала различия между тремя видами (setosa, versicolor, virginica) на основе длины и ширины чашелистика. Использование различных цветов для классов улучшило восприятие данных и их интерпретацию.
2. График динамики уровней CO2 показал, как данные изменялись с течением времени, что позволяет делать выводы о тенденциях и изменениях в окружающей среде. Наглядная визуализация временных рядов позволяет лучше понять долгосрочные изменения и их возможные причины.
