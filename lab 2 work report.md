# Цель и задачи лабораторной работы
Цель данной лабораторной работы заключается в разработке программы, которая вычисляет вес протеиновой последовательности на основе заданного взвешенного алфавита аминокислот. Основные задачи включают:
1. Определение весов аминокислот в соответствии с моноизотопной массой.
2. Реализация алгоритма для подсчета общего веса протеиновой последовательности.
3. Обработка пользовательского ввода и вывод результата в удобочитаемом формате.
# Инструменты и алгоритмы, использованные в этой работе
Писали код на языке python в программе PyCharm CE, так как это самый удобный способ
В данной лабораторной работе использованы следующие инструменты и алгоритмы:
* Словарь (dictionary) - для хранения весов аминокислот, что позволяет быстро получать вес по символу.
* Функция sum() - для суммирования весов всех аминокислот в введенной последовательности.
* Генераторное выражение - для удобного и эффективного перебора элементов последовательности и получения их весов.

Алгоритм:

Инициализация данных: Код начинает с определения словаря sza, где каждой аминокислоте (обозначенной одной буквой) сопоставляется её молекулярная масса.

Считывание пользовательского ввода: Пользователь вводит строку, представляющую последовательность аминокислот (например, "ACDEFGHIK"). Введённое значение сохраняется в переменной protein.

Вычисление суммарной массы: С помощью генератора списка (или, точнее, конструкции генератора) код проходит по каждому символу из строки protein, находит соответствующую массу в словаре sza и суммирует эти значения, получая общую массу белка.

Вывод результата: Итоговая сумма выводится на экран с использованием f-строки, где результат форматируется так, чтобы показывать три знака после запятой.
# Выводы
В результате выполнения лабораторной работы была успешно разработана программа, позволяющая вычислять вес протеиновых последовательностей на основе заданного алфавита аминокислот. Программа корректно обрабатывает ввод пользователя и выводит результат с точностью до трех знаков после запятой.
